# StudentHub

StudentHub is a full-stack student management web application built using Spring Boot, MySQL, HTML, CSS, and JavaScript.

## Features

- Student Login
- Add Student
- View Student List
- Update Student Details
- Delete Student
- Search Students

## Technologies Used

- Java
- Spring Boot
- MySQL
- HTML
- CSS
- JavaScript

## How to Run

1. Open project in IntelliJ
2. Configure MySQL
3. Run Spring Boot application
4. Open:
http://localhost:8081/login.html
